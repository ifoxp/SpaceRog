# SpaceRog

2D мобільний космічний шутер для Android на Unity. Виживаєш у хвилях, збираєш
валюту, купуєш кораблі й бафи, виконуєш щоденні квести.

Це проєкт, на якому я вивчив ту частину геймдеву, що не є геймплеєм:
монетизацію, збереження прогресу, магазини, локалізацію, онбординг. Виявилось,
що саме вона і займає більшість роботи.

## Що всередині

Дев'ять сцен у збірці:

| Сцена | Призначення |
|---|---|
| Menu | вхід |
| Survival | сама гра |
| Hangar | твої кораблі |
| ShipShop / BuffShop | витрата валюти |
| Quests | щоденні завдання |
| Magazine | внутрішні покупки |
| Ranking | результати |
| Setting | налаштування і мова |

Поруч із геймплеєм: Unity Ads із міжсторінковою рекламою та відео за
винагороду, внутрішні покупки, система щоденних квестів зі скиданням за
розкладом, туторіал і підказки для новачків, Unity Localization.

## Технічні деталі

Unity 2021.3.4f1, збірка під Android.

Прогрес зберігається через `PlayerPrefs` — куплені кораблі, бафи, валюта, стан
квестів і результати. Для гри такого розміру це найпростіше робоче рішення.

Відео за винагороду вбудоване в економіку, а не причеплене збоку: перегляд
реклами — один зі способів заробити валюту, тож реклама має місце в грі, а не
лише перериває її.

## Чесна оцінка

У коді видно, що це моя перша випущена гра. `GameManager` — статичний
сінглтон, що призначається в `Start()`, а це ламке, якщо колись зміниться
порядок виконання скриптів. `PlayerFly.cs` розрісся до 458 рядків. Іменування
місцями непослідовне, а частина ключів `PlayerPrefs` збирається конкатенацією
рядків.

Нічого з цього я тут не ховаю, бо проєкт усе одно вартий показу: це завершена
гра з робочою комерційною частиною, і побудувати це від початку до кінця дало
мені більше, ніж дав би чистіший, але недороблений прототип.

## Збірка

Відкрити в Unity 2021.3.4f1 і зібрати під Android. Keystore не включений.
